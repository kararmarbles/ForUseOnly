# Recording Software

A lightweight, professional desktop screen, webcam, and audio recording application for Windows and macOS.

## Features

- **Screen & Display Capture:** High-performance entire screen, window, or custom region recording.
- **Webcam & Audio:** Picture-in-picture webcam overlay, microphone recording, and system sound capture.
- **Accurate Video Generation:** Native Matroska (.mkv) container format with accurate EBML duration metadata for smooth timeline scrubbing in Windows Media Player, Movies & TV, and mobile players.
- **Auto-Split & Continue:** Automatic segmenting and seamless recording continuation when time limits are reached.
- **Background Mode:** Auto-minimize to taskbar/tray during active recording.
- **Auto-Updates:** Integrated background update checking and 1-click update installation.

## Installation

Download the latest installer `Recording Software Setup X.X.X.exe` from the [Releases](https://github.com/kararmarbles/ForUseOnly/releases) page.

## Development

```bash
# Install dependencies
npm install

# Run Vite dev server
npm run dev

# Start Electron app in development mode
npm run electron:start

# Build production installer
npm run electron:build
```
